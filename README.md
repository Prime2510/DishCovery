# DishCovery

DishCovery is a recipe-sharing web application designed to help users create, share, update, and collaboratively develop recipes with friends.

## Project Purpose

The purpose of this project is to design the core user interface for a recipe-sharing web application. DishCovery will allow users to:

- Create and manage personal recipes.
- Share recipes with friends.
- Grant editing rights to other users.
- Add updates, modifications, and variations to existing recipes.
- Track who contributed each change or addition.

The interface is designed to provide a clear foundation for the later development assignments, while supporting the Five E's of usability:

- **Effective** – Users can complete recipe-related tasks successfully.
- **Efficient** – Common actions can be completed quickly and with minimal effort.
- **Engaging** – The application is visually appealing and encourages collaboration.
- **Error-tolerant** – The design helps prevent mistakes and provides useful feedback when errors occur.
- **Easy to learn** – New users can understand the interface and its features quickly.

## Assignment Roadmap

This project is the first stage of a larger development process. Future assignments will build directly on the interface and design decisions made here:

1. **Assignment 2 – HTML and CSS**
   - Build the user interface using HTML and CSS.
2. **Assignment 3 – JavaScript Form Validation**
   - Add client-side validation to improve form usability and error handling.
3. **Assignment 4 – Database Design and Implementation**
   - Design and implement the database needed to store users, recipes, permissions, updates, and contributions.
4. **Assignment 5 – PHP Back-end Programming**
   - Implement server-side functionality and connect the interface to the database.
5. **Assignment 6 – AJAX-based Updating**
   - Add asynchronous updates to improve responsiveness and reduce unnecessary page reloads.

## Interface Design Goals

Because later assignments will build upon this work, the interface is intended to include all major elements required for the complete application. The design should provide users with intuitive ways to:

- Browse and view recipes.
- Create new recipes.
- Edit recipes they own or have permission to modify.
- Share recipes with friends and manage editing rights.
- Add recipe updates and variations.
- View the history of changes and identify contributors.
- Receive feedback about successful actions and errors.

The interface design follows usability principles covered in the course and provides a foundation that can be expanded and refined during subsequent assignments.

## Project Status

This repository currently contains the interface design stage of DishCovery. Additional functionality, including validation, database integration, PHP back-end processing, and AJAX updates, will be added in future assignments.
